# LowLevelDotNET

**LowLevelDotNET** is a C# console application built from scratch as a foundation for a future Web API.  
The project showcases **clean architecture**, **scalability**, and **practical .NET development skills**, making it a solid demonstration of backend fundamentals.

## Features

- Console application structure ready for evolution into a Web API
- Demonstrates C# and .NET best practices
- Easily extensible for future development
